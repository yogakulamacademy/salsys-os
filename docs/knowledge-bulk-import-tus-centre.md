# Resumable upload and Import Centre review checkpoint
Uses Supabase documented TUS direct Storage host and 6 MiB chunks (https://supabase.com/docs/guides/storage/uploads/resumable-uploads), access-token forwarding, reserved canonical path, no upsert header, and no persistent TUS fingerprint. No TUS package installed, no request initiated, no token issuance or server reservation route. Actual client integration requires a pinned tus-js-client dependency and lockfile, fresh server-authorized reservation, same-session token refresh, URL/origin validation for returned upload location, progress/error/cancel behavior, expiry and restart reconciliation. Automatic network retry within same in-memory upload is intended; cross-page resume is deliberately disabled until secure ownership of resume handles is proven. Client metadata/size checks are not access control. Provider must independently enforce exact insert-only reservation, size, completion and expiry; RLS must consider all existing permissive policies, deny overwrite/read/list/delete as appropriate, verify resumable creation/PATCH completion with revoked session, and handle abandoned uploads. See https://supabase.com/docs/guides/storage/security/access-control. No bucket or RLS installed.
Unmounted React Import Centre component consumes only bounded projected history metadata, shows progress, seven outcome counts, empty/unavailable state and clearly disabled upload. No route, polling, cancellation/recovery or authorization bypass. Counts are per loaded view, not organization totals; file names absent from authorized history contract. No mock production rows. Future authorized loader must preserve exact database cursor timestamps and bind current tenant session; no raw paths or tokens in UI. UI not visually rendered in this checkpoint. Full-size performance, restricted role ownership, actual Storage broker and scheduler, cleanup, review and acceptance remain open. Existing importer untouched; no hosted execution, dependency changes, merge, deployment or staging lift.
