# Knowledge bulk import — phase 1 (draft, offline only)
Target: 50 MiB / 10,000 JSON entries per file. Existing import stays unchanged. Current Next server action has no body-size override; Vercel limits require a separate upload design, not a global size increase. The pure preflight rejects oversized/malformed files and entries rather than silently truncating them; detects normalized exact duplicates within one file; prepares <=50 entries and <=512 KiB JSON-array batches. The byte cap is for the array, not a full HTTP envelope. Current 8,000-character content limit retained until downstream retrieval and database constraints are reviewed. 25,000-character logical documents/chunking remain proposed. No live imports, storage, jobs, writes, approval or processing introduced by this phase.
