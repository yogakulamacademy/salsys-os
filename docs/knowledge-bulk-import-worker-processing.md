# Worker claim and draft finalization checkpoint (review only)
Adds worker-specific SECURITY DEFINER functions to the non-exposed review schema, no grants outside isolated CI. Actual session_user delegation and original administrator membership/session checked under parent lock for each call. Worker claim records login ownership and caps lease by job and delegation expiry; manual finalize/failure settlement rejects worker-owned leases; terminal transitions clear ownership. Worker finalization rechecks token, attempt, login, expiry and payload digest, validates allowed payload fields, creates a source/document/chunk with explicit original actor and hardcoded draft state, and updates ledger atomically. Does not impersonate Auth or grant the existing approval-capable RPC. Direct draft-only insert is a candidate narrowly scoped creation boundary using existing tables, not reuse of the public creation RPC; production must reconcile its validation, provenance and audit semantics with the canonical creation path and actual full migration graph before adoption. No approval, update/delete or general CRM privileges. Tests exercise real restricted login, denied direct access, cross-tenant refusal, forged approval, lease mismatch, rollback, original actor attribution, stale claim, revocation. Worker finalization replay rejects stale token; durable authorized result lookup and unknown-outcome recovery still needed for worker itself. Worker retry settlement, renewal, role ownership/grant hardening, actual storage immutability, UI and scheduler remain open. No application grants, migration, hosted execution or staging lift. Current fixture uses synthetic Auth.
