## Scope closed

R10-P1 delivers a separate deterministic **Recommended actions** layer on the privileged `/home` Command Center using only current CRM operating evidence:

- reply backlog;
- overdue follow-ups;
- first touch needed;
- payment pending.

P1 does not activate predictive conversion probabilities, AI-generated recommendation prose, autonomous external/customer/provider actions, P2 feedback controls, or P3 outcome observation.

## Final runtime invariants

Production enforces:

- tenant authority from authenticated session/workspace context;
- owner/admin/manager presentation boundary;
- authenticated POST-only presentation with private/no-store response;
- persistent tenant-scoped signal episode state;
- observed clear -> recur episode progression;
- same active episode reused across target membership churn;
- working target set capped at 50 Leads;
- full aggregate baseline retained independently of the working set;
- canonical deterministic admissions priority evidence used for ordering;
- score labels are not probability or model confidence;
- recommendation/event tables remain directly SELECT-only to authenticated clients;
- hardened privileged RPC performs mutation;
- existing terminal episode key fails closed with `INTELLIGENCE_EPISODE_TERMINAL`;
- partial per-signal failures preserve successful persisted presentations;
- existing factual Home panels are not replaced by inferred fallback content.
